ZANZIBAR RP / LUX EDITORIAL SITE

1. Распакуйте архив.
2. Откройте index.html.
3. Для GitHub Pages загрузите СОДЕРЖИМОЕ папки Zanzibar_Lux_Complete (включая assets) в корень репозитория.
4. В Settings -> Pages выберите main / (root).

Раздел map.html использует внешнюю интерактивную карту https://www.izurvive.com/lux/.
Если сторонний сайт запрещает встроенный iframe, откройте карту по прямой ссылке на странице.

ОРИГИНАЛЬНЫЙ_ЛОР.txt сохранен без изменений из предыдущего проекта.
Новые разделы и подробные правила дополняют авторский текст.
Числовые нормы RP предлагаются к утверждению администрацией, они не объявлены действующими.

Локальные картинки являются сгенерированными иллюстрациями, а не скриншотами Lux.
Фото занзибарского колобуса грузится с Wikimedia Commons (автор Makeche, Public domain).

Страницы: index, lore, map, factions, faction-*, civilians, groups, group-*, rules, nature, stories, gallery, original, credits.

Проект вымышленный. Не описывает реальные вооруженные конфликты, политическую или религиозную ситуацию на настоящем Занзибаре.
