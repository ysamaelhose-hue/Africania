ЗАНЗИБАР RP / MULTIPAGE EDITORIAL SITE

1. Распакуйте ZIP в отдельную папку.
2. Откройте index.html в браузере.
3. Чтобы опубликовать, загрузите всё содержимое папки на веб-хостинг, сохраняя структуру.

Все страницы и локальные иллюстрации работают без интернета. На странице природы две настоящие фотографии из Wikimedia Commons подгружаются по возможности, при отсутствии сети показываются локальные иллюстрации.

ОРИГИНАЛЬНЫЙ_ЛОР.txt: текст пользователя, сохранённый без изменений.
Дословные фрагменты лора распределены по страницам История, Фракции, Мирные жители, RP-группы и Сюжеты.
Правила RP: проект, а не окончательный утверждённый регламент. Лимиты уточнить перед публикацией.

Раздел «Природа» и фотографии являются художественными визуализациями, не утверждёнными фактами игрового лора.
